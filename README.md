# SmileedNexus

Красивая, быстрая и лёгкая панель эмодзи для React.

## Особенности

**Поиск на русском языке** (по словам: привет, пока и т.п).
**Совместимость с React 18-19** (никаких конфликтов зависимостей).
**Текстуры Twemoji** (одинаковые смайлы на Windows, macOS, Android и Linux).
**Ноль зависимостей** (кроме самого React).
**Интеграция с `contenteditable`** (вставляет эмодзи точно туда, где стоит курсор).
**Идеальный рендер** составных эмодзи (радужный флаг 🏳️‍🌈, семьи 👨‍👩‍👧‍👦) благодаря `Intl.Segmenter`.

## Поддержка платформ и браузеров

Благодаря использованию локального SVG-спрайта (Twemoji) и нативного API `Intl.Segmenter`, панель **работает абсолютно одинаково** на всех операционных системах.
